# 🌐 Personal Portfolio Website

This is my **personal portfolio website** created using **HTML, CSS, and JavaScript**.  
It showcases my skills, about me section, and a contact form in a clean and modern UI.

---

## 👨‍💻 About Me

Hello! I'm **Darshak Kalathiya**, a Web Developer and BCA second-year student.  
I am passionate about web development and love solving problems by building creative and dynamic websites.

---

## 🚀 Features

- Responsive and modern UI design  
- Smooth navigation (Home, Skills, About Me, Contact)  
- Skills section with progress bars  
- About Me section with personal details  
- Contact form layout  
- Social media icons  
- Clean and beginner-friendly code  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3
